WoW Sync
▾
This feature needs Chrome or Edge — your browser doesn't support the File System Access API it relies on to read your addon's saved data.
Why this exists: a WoW addon can never make a network call, so it can't talk to RaidLead on its own — this page is the bridge. Chrome/Edge also won't let a website reach anything inside Program Files, which is where WoW normally lives, so a small local script relays data through a separate folder instead — this page only ever touches that folder, never your WoW install directly.
One-time setup: Download RaidLead — the zip has two folders:
• RaidLead — copy this into ...\_retail_\Interface\AddOns\.
• RaidLead Docs — this acts as a bridge. Put it in your Documents folder. It just lets the addon and this site read/write data back and forth; the addon won't actually sync anything without it.

Then download RaidLead Companion and install it, Windows might try to block it, but it's safe to run — this is the small companion-app that keeps the AddOn and the "RaidLead Docs" folder in sync. In its Settings, connect it to your WoW AddOns folder and "RaidLead Docs".

Then click Connect below and select the RaidLead Docs folder (wherever you put it).
Night to night, once set up:
• RaidLead Companion should just stay running in the background (it starts with Windows automatically) — you never need to click anything inside it.
• Before a raid: publish your roster on Raid Night. Companion picks it up within moments; /reload in-game to see it.
• After a raid: log out or /reload so WoW saves this session's loot to disk, then come back here and press Sync Now once. That's the one manual step that can't be automated — your browser needs an actual click to read the folder.
